# 🚀 PortfolioHub

PortfolioHub is an **admin-panel-based web application** developed with **ASP.NET Core 5.0**, designed to showcase personal portfolio information and manage website content.

The project consists of three main sections: the **Main Panel**, where personal information is presented to visitors; the **Author Panel**, where registered users can perform various operations; and the **Admin Panel**, which provides complete management and control of the application's content and users.

## 📌 Panels

### 🏠 Main Panel

The main panel presents the user's professional and personal portfolio information.

* About Me
* Services
* Skills
* Projects
* Experiences
* References
* Contact Information

### 👤 Author Panel

The author panel allows registered users to manage their accounts and communicate through the system.

* Messaging
* Viewing announcements
* Profile editing
* Password changing

### ⚙️ Admin Panel

The admin panel provides complete management and control over the application.

* User and content management
* Project, experience, and reference management
* Message and announcement management
* Application management

## 🛠️ Technologies & Tools

* **ASP.NET Core 5.0** – Web application development
* **Entity Framework Core** – Database operations
* **SQL Server** – Database management
* **Code First** – Database creation and management
* **N-Tier Architecture** – Layered project structure
* **Repository Pattern** – Data access management
* **Unit of Work** – Managing business operations
* **FluentValidation** – Data validation
* **MVC** – Model-View-Controller architecture
* **ASP.NET Core Identity** – Authentication and authorization
* **Ajax** – Dynamic operations without page refresh

## 🏗️ Architecture

The project was developed using **N-Tier Architecture**.

```text
Presentation Layer
        ↓
Business Layer
        ↓
Data Access Layer
        ↓
Entity Layer
```

This architecture separates the responsibilities of the application into different layers, resulting in a more **organized, maintainable, and scalable** project structure.

## 🔐 Authentication & Authorization

**ASP.NET Core Identity** is used to provide user authentication and role-based authorization.

* User login
* User registration
* Password changing
* Role-based authorization
* Admin and user access control
